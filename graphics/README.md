# Graphics Project

This repository contains the assets and source code for the **Graphics** project—a set of interactive pages demonstrating design principles, elements, colors, shapes, animations, and branding.

## Getting Started

1. Clone this repo:
   ```bash
   git clone https://github.com/yourusername/graphics.git
   cd graphics
   ```
2. Open any of the HTML files in your browser:
   - `index.html` — Home page overview
   - `principles.html` — Design principles
   - `elements.html` — Graphic elements
   - `colors.html` — Color theory
   - `shapes.html` — Shape meanings
   - `animations.html` — Animation demos
   - `branding.html` — Branding guidelines
